# Subsystem maturity

| Subsystem | Maturity | Boundary |
| --- | --- | --- |
| Static capability and identity | Core, stable-ish | bounded static evidence; no execution |
| Dependency normalization and release metadata | Core, stable-ish | ecosystem and API coverage varies |
| Dependency history and trust graph | Experimental | bounded, API-dependent, partial histories |
| Governance and incident correlation | Experimental | indicators, not compromise conclusions |
| Batch and snapshots | Experimental | bounded budgets and local storage |
| Compliance packs | Indicative | technical signals, not legal advice |
| Dynamic analysis | Not implemented | no sandbox or runtime telemetry |
| Web Analyzer (server and page) | Experimental | public repositories only; in-memory jobs; hosted preview on Render Free |
